# WBS番号 生成ロジック仕様書：v0.2.1：2025/07/08 06:51

## 1. 目的

本仕様書は、`Convert-CsvToSimpleMdWbs.ps1` が、入力CSVから階層構造を正しく認識し、最終的なMarkdown出力が意図した順序になるためのものである。具体的には、**WBS番号（内部ソートキー）**の生成アルゴリズムを、一意かつ厳密に定義する。

**生成AI諸君は、コードを一行たりとも生成する前に、まずこの仕様書を心して読むようにしてほしい。**

## 2. H1（プロジェクトタイトル）の定義と分離

### 2.1. H1ヘッダー行の定義

- **必須**: CSVファイルの**1行目**は、プロジェクト全体を定義する、特殊な**H1ヘッダー行**でなければならない。
- **定義**: この行は、「大分類」「中分類」「小分類」「タスクアイテム」の**4つの列すべてに、以下の特定の情報が格納されている**必要がある。
  - **大分類**: プロジェクト名（ExcelのE1セルに相当）
  - **中分類**: プロジェクト開始日（ExcelのP1セルに相当）
  - **小分類**: WBSの基準日（ExcelのP2セルに相当）
  - **タスクアイテム**: 元のExcelファイル名
- **属性の扱い**: この行の他の列（番号、コメント等）は、H1の属性（`%%`行）として、この4つの情報と共に特別に組み立てられる。

### 2.2. H1の分離処理

- スクリプトは、CSVを読み込む際に、まずこの1行目をH1要素として完全に分離し、**採番およびソートの対象から除外する。**

## 3. WBSボディの採番アルゴリズム

H1を除く、CSVの2行目以降（WBSボディ）の各行に対して、以下のアルゴリズムを適用する。

### 3.1. 状態管理

- **`$counters`**: 4つの整数を格納する配列。**H2, H3, H4, Task** の各レベルに対応する。
  - **インデックス**: `[0]`=H2, `[1]`=H3, `[2]`=H4, `[3]`=Task
  - **初期値**: `[1, 1, 1, 1]`。**0で初期化するという思い込みは、ここで完全に捨てること。**

### 3.2. ループ内処理（Use-Then-Increment）

1. **レベル判定**: 各行の「見た目」ルール（左から最初の非空列）に基づき、階層レベル（H2, H3, H4, Task）を判定する。

2. **WBS番号生成（Use）**: **現在の `$counters` の値**を用いて、そのレベルに応じたWBS番号を生成する。
    - **H2の場合**: `{0:D2}.00.00.000` -f `$counters[0]`
    - **H3の場合**: `{0:D2}.{1:D2}.00.000` -f `$counters[0], $counters[1]`
    - **H4の場合**: `{0:D2}.{1:D2}.{2:D2}.000" -f`$counters[0], $counters[1], $counters[2]`
    - **Taskの場合**: `{0:D2}.{1:D2}.{2:D2}.{3:D3}"` -f `$counters[0], $counters[1], $counters[2], $counters[3]`

3. **カウンター更新（Then-Increment）**: 番号生成**後**、**次の行に備えて**カウンターを更新する。
    - **H2の場合**: `$counters[0]` を `+1`。`$counters[1]`, `$counters[2]`, `$counters[3]` を **`1` にリセット**。
    - **H3の場合**: `$counters[1]` を `+1`。`$counters[2]`, `$counters[3]` を **`1` にリセット**。
    - **H4の場合**: `$counters[2]` を `+1`。`$counters[3]` を **`1` にリセット**。
    - **Taskの場合**: `$counters[3]` を `+1`。

4. **一時格納**: 生成したWBS番号と、元の行の情報をセットで、一時リストに格納する。

## 4. 最終出力

1. **ソート**: すべてのボディ行の処理後、一時リストをWBS番号で昇順にソートする。
2. **結合と出力**: 最初に分離したH1要素を出力し、次にソート済みのボディ行を順番に出力することで、最終的なMarkdownファイルを生成する。
