# MD-WBS-Tools 開発ロードマップ

## 1. 全体方針

本プロジェクトは、**Excelで管理されているプロジェクト情報を、Microsoft Copilotがもっとも理解しやすい`simple-md-wbs`形式へ変換すること**を主目的とします。

* **Excelが正:** プロジェクトのWBS（Work Breakdown Structure）に関する最新情報は、常にExcelファイルにあるものとします。
* **Copilot連携ファースト:** すべての機能開発は、Copilotによる解釈精度と利便性を向上させるために行います。
* **段階的アプローチ:** まずはExcelから`simple-md-wbs`への最低限の変換機能を実現します。その有効性を確認しながら、数式解析や依存関係の反映など、より高度な機能を段階的に追加します。
* **PowerShell + COM:** Excelファイルの操作は、PowerShellからCOM（Component Object Model）を経由して行い、Excelファイル自体へのマクロ埋め込みは避けます。

---

## 2. 開発フェーズ

### フェーズ 1: Excel → `simple-md-wbs` 変換基盤の構築（最優先）

* **目的:** Excelファイルから基本的なWBS情報を抽出し、`simple-md-wbs`形式で出力するコア機能を実現する。
* **主要タスク:**
    1. **Excel読み取り機能の実装:**
        * PowerShellからCOM経由でExcelファイルを読み込む。
        * 指定されたシートから、「大分類」「中分類」「小分類」「タスクアイテム」といった列情報に基づき、基本的な階層構造とタスク名を抽出する。
    2. **基本属性のマッピング:**
        * ユーザー記述ID、担当者、ステータスなど、Copilotの理解に不可欠な基本的な属性を抽出し、`simple-md-wbs`の属性としてマッピングする。
    3. **変換スクリプトの開発:**
        * `Convert-ExcelToSimpleMdWbs.ps1`（仮称）を新規に作成する。
    4. **テストとドキュメント:**
        * 基本的な変換処理のテストを実装する。
        * ユーザーマニュアルに、本機能のセットアップと基本的な使い方を記述する。
* **このフェーズで**行わない**こと:**
  * Excelの数式（日付計算など）の解析。
  * Excelのグループ化機能の解析。
  * 複雑な依存関係（先行タスクIDなど）の解決。

### フェーズ 2: `simple-md-wbs` ⇔ CSV 相互変換機能の整備

* **目的:** `simple-md-wbs`を中間形式として、他のツール（例: ガントチャートツール）と連携するためのCSV入出力機能を提供する。
* **位置づけ:** Excel連携機能を補完し、ツールの活用範囲を広げるための機能。
* **主要タスク:**
    1. **`SimpleMdWbs` → CSV 変換:**
        * 既存の`Convert-SimpleMdWbsToCsv.ps1`を完成させる。
        * 先行タスクIDを解決し、依存関係をCSVに出力する機能を含める。
    2. **CSV → `SimpleMdWbs` 変換:**
        * `Convert-CsvToSimpleMdWbs.ps1`を開発し、CSVから`simple-md-wbs`への逆変換を実現する。
    3. **テストとドキュメント:**
        * 相互変換のラウンドトリップテストを整備する。
        * ユーザーマニュアルに関連機能の使い方を追記する。

### フェーズ 3: Excel連携機能の高度化

* **目的:** フェーズ1で構築した変換機能を発展させ、Excel内のよりリッチな情報を`simple-md-wbs`に反映させることで、Copilotの理解精度をさらに向上させる。
* **主要タスク:**
    1. **数式・計算結果の反映:**
        * Excelの数式で計算されている日付や工数などの**計算結果の値**を抽出し、`simple-md-wbs`の属性（開始日、終了日、日数など）にマッピングする。
    2. **依存関係の解析:**
        * 数式の参照関係などからタスク間の依存関係を推測し、先行タスクIDとして`simple-md-wbs`に反映させる。
    3. **グループ化情報の活用:**
        * Excelのグループ化（アウトライン）情報を解析し、より正確な階層構造を`simple-md-wbs`で再現する。
    4. **エラーハンドリングと堅牢性の向上:**
        * 多様なフォーマットのExcelファイルに対応できるよう、エラー処理を強化する。

### フェーズ 4: 安定化と改善

* **目的:** ツール全体の品質を向上させ、ユーザーからのフィードバックに基づいた改善を行う。
* **主要タスク:**
  * テストカバレッジの向上。
  * パフォーマンスチューニング。
  * コマンドレットの`パラメータ`や出力形式を、より使いやすく改善する。
  * ドキュメント全体の品質向上とメンテナンス。
