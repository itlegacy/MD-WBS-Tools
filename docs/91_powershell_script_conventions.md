# PowerShell スクリプト規約（追加ルール）

## 1. Excel ファイルの処理

### 1.1. 対象ワークシートの選定（最重要ルール）

PowerShellスクリプトでExcelファイルを処理する場合、**いかなる場合も、一番左に位置するワークシート（インデックス `1`）を処理対象としなければならない。**

*   **理由**:
    *   `wbs` や `Sheet1` といった特定のシート名に依存すると、利用者の環境によってスクリプトが失敗するケースが多発した。
    *   操作対象のシートを「一番左のシート」に統一することで、スクリプトの堅牢性と予測可能性を最大限に高める。

*   **実装**:
    *   スクリプトは、シートを名前（例: `$workbook.Sheets.Item("wbs")`）で参照するのではなく、必ずインデックス（`$workbook.Sheets.Item(1)`）で参照すること。
    *   シート名に関する`パラメータ`（例: `-SheetName`）は、混乱を避けるために廃止し、スクリプトから削除すること。
