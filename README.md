# MD-WBS-Tools プロジェクト

## プロジェクト概要

このプロジェクトは、Excelで管理されているWBS（Work Breakdown Structure）情報を、Microsoft CopilotなどのAIアシスタントが解釈しやすい`simple-md-wbs`形式へ変換するツール群を提供します。
